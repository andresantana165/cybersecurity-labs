# cybersecurity-labs
Laboratórios práticos de redes, cybersecurity, inforfirewall, SOC, SIEM e segurança da mação.
Desenvolvidos para estudar e aplicar conceitos de segurança da informação. O repositório reúne exercícios, ambientes de testes, ferramentas e documentações voltados para redes, sistemas, monitoramento, hardening, análise de vulnerabilidades e defesa cibernética.
